# 坚持焦虑地花钱中

**Spending Anxiously, Consistently.**

一个只给自己用的 Android 记账小工具。

当前进入 **2.0 系列**：支出 / 收入录入已经接通，第二页开始升级成完整的数据统计、数据分析与财报后台。

当前目标：

- 首页按“天”分组展示每一笔详细记录
- 支持支出 / 收入两种记录类型
- 第二页提供数据统计、数据分析与财报三个模块
- 本地保存数据，不依赖服务器
- 支持金额、分类、备注、日期、支付来源与多币种记录
- 外币记录保存当时汇率及折算后的人民币金额
- 常用备注按真实账单出现次数识别，重复 3 次及以上后进入稳定标签体系
- GitHub Actions 自动构建 Debug APK，方便只有安卓手机时直接拿构建产物测试

### 数据统计

统一使用 **月 / 年 / 自定义** 时间前置筛选。

第一层：

- 分类饼图
- 拉通所有分类的常用备注金额条形图

第二层：

- A：当前分类常用备注金额折线图，x 轴为常用备注，y 轴为金额
- B：当前分类时间趋势折线图，x 轴为时间，y 轴为金额，右上角可筛选常用备注
- `书籍` 分类跳过常用备注二层，直接进入原始账单明细

第三层：

- 对应常用备注的真实账单明细

### 数据分析

- 环比 / 同比，同时显示百分比与金额差
- 变化归因：定位哪些分类推动了本期变化
- 频率 × 单价：区分“买勤了”和“买贵了”
- 异常偏离：只与自己的历史基线比较
- 稳定性分析：识别长期稳定出现与金额波动较大的常用备注

### 财报

财报抬头：**ABC王国责任不怎么有但一定爽公司**。

- 半年度财务报告：应用内弹窗查看
- 年度财务报告：可生成并保存纵向一图流 PNG
- 年报包含收入、支出、净结余、同比、分类 TOP、常用备注 TOP、支付渠道、峰值月份、最大单笔与年度记录数
