# 坚持焦虑地花钱中

**Spending Anxiously, Consistently.**

一个只给自己用的 Android 本地记账工具。

## 当前稳定版

**2.0 已封版。**

稳定基线：`v2.0.68`  
稳定分支：`release/2.0.68`

2.0 的目标已经完成：日常记账、旧账导入、记录检索、统计分析和财报形成完整闭环。后续新功能原则上进入 3.0，不再继续往 2.0 堆功能。

## 记录

- 支出 / 收入两种记录类型
- 首页按天分组展示真实流水
- 支持编辑、删除
- 支持分类、备注、日期、支付来源
- 支持 CNY / USD / KRW / JPY
- 外币保存原币金额、记账时汇率和人民币折算金额
- 计算器支持 `+ - × ÷`
- 日期支持手动输入，以及 `-1天 / 今天 / +1天`
- 支付来源用彩色圆点显示
- 常用备注按真实账单出现次数识别，达到 3 次后进入标签体系
- 常用备注按点击频率、实际出现次数和最近使用时间排序

### 搜索与筛选

- 关键词模糊搜索，不要求全字匹配
- 多个关键词用空格分隔，按 AND 逻辑匹配
- 可搜索分类、分类副标题、备注、日期
- 日期搜索格式：`yyyymmdd`
- 年份筛选
- 月份筛选
- 一键返回页面顶部
- 切换到分析页再回来时，保留搜索条件、年月筛选和列表位置

## 批量导入

当前支持 **CSV**。

- Android 文件选择器直接选文件
- 导入前先预览
- 显示读取行数、可导入数量、支出/收入数量与金额
- 校验日期、收支类型、金额、分类、币种、人民币金额、支付来源
- 自动跳过完全重复的账单
- 错误行不会写入正式账本
- 额外列自动忽略，方便保留旧分类、旧备注等清洗辅助信息
- 适合“修完一个月，导一个月”的旧账整理流程

## 数据统计

统一使用 **月 / 年 / 自定义** 时间筛选。

第一层：

- 总支出、总收入、净结余、记录数
- 分类结构饼图
- 全局常用备注统计

第二层：

- A · 备注金额：竖向柱状图，x 轴为备注，y 轴为金额
- B · 时间趋势：按时间展示金额走势，并可筛选常用备注
- 书籍分类跳过常用备注二层，直接进入原始账单

第三层：

- 展示真实账单明细
- 点击明细可直接调用“修改这笔”编辑框

## 数据分析

全部只基于自己的真实账本计算：

- 环比 / 同比：百分比 + 金额差
- 变化归因：定位推动本期变化的分类
- 频率 × 单价：区分“买勤了”和“买贵了”
- 异常偏离：与自己的历史基线比较
- 稳定性分析：观察过去 12 个月的出现频率与金额波动

## 财报

财报抬头：

**ABC王国责任不怎么有但一定爽公司**

- 半年度财务报告：应用内弹窗查看
- 年度财务报告：生成纵向一图流 PNG 并保存到相册
- 年报包含收入、支出、净结余、同比、分类 TOP、常用备注 TOP、支付渠道、峰值月份、最大单笔和年度记录数

## 3.0 候选方向

优先级暂定：

1. 完整账本备份 / 恢复
2. 导入批次记录与“一键撤销本次导入”
3. 数据修理厂：搜索结果多选、批量改分类 / 备注 / 支付来源
4. 收入侧更完整的统计与分析
5. 固定支出 / 订阅识别
6. 半年报、年报历史与重新生成
7. 数据层从 SharedPreferences 逐步迁移到更适合长期账本的结构
8. 自动测试：计算器、CSV 导入、时间窗口、统计汇总
9. 继续拆分过大的 UI / Analytics 文件，降低后续改动互相误伤的概率
